All notable changes to **ReelCount** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-10-18

### Added
- **Multi-Platform Support**: Robust real-time reel detection for Instagram Reels, Facebook Reels, and YouTube Shorts.
- **Smart Deduplication Guard**: 1.2-second minimum swipe cooldown and 6-second re-entry protection to eliminate duplicate counts.
- **Movable Floating Live Badge**: Minimal circular counter showing only the total number of reels watched today with smooth drag-and-drop repositioning and 1200ms exit debouncing.
- **Cognitive Digital Wellbeing**: Real-time velocity tracking (reels/hour), average dwell time, daily goals with threshold alarms, and dynamic brain state transitions (Fresh 🧠✨ to Brain Rot 💀💥).
- **Progress & Analytics Tab**: Hourly breakdown for today and daily breakdown for the week with responsive visualizations.
- **Home Screen Widget**: Quick-glance widget displaying daily reel count and dwell time directly on the Android home screen.
- **Obsidian & Warm Amber Theme**: Pure dark AMOLED theme with warm amber accents (`#F59E0B`).
- **Developer Diagnostics Panel**: Toggleable diagnostic tab with live event logs and inspection telemetry for open-source development.
- **100% Offline & Private**: Zero network permissions (`INTERNET` permission removed) ensuring all data stays strictly on-device.
